About Our Library Management System

The Library Management System is a web-based application developed to simplify and automate library operations. It provides separate facilities for administrators and users.

Project Objectives

The main objective is to manage books, users, reservations, book issues, returns and fines efficiently using a centralized database.

Admin Features

Administrators can manage books, manage users, approve or reject reservations, approve returns, manage fines, view contact messages and generate reports.

User Features

Users can register, log in, search available books, request reservations, view issued books, request returns, check fines, update profiles and contact the administrator.

Technologies Used

Frontend: HTML, CSS and JavaScript
Backend: Java, Jakarta Servlets and JSP
Database: PostgreSQL
Database Tool: DBeaver
Build Tool: Maven
Server: Apache Tomcat 10.1
