# Online Reservation System

## Project Overview

The Online Reservation System is a Java-based desktop application developed using Java Swing. It provides a graphical interface for managing reservations.

## Technologies Used

- Java
- Java Swing
- Maven
- Database (add the actual database name)

## Main Components

- LoginFrame
- ReservationFrame
- DatabaseInitializer
- DBConnection
- PasswordUtil

## Project Structure

- `src/main/java` – Java source files
- `pom.xml` – Maven configuration

## How to Run

1. Clone or download the project.
2. Open it in IntelliJ IDEA.
3. Configure the database connection.
4. Build the project using Maven.
5. Run the Main class.
